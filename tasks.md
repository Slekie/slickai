# Slick AI — Mobile App: Full Spec & Implementation Tasks

> **Platform:** React Native (Expo ~54) · TypeScript · Zustand · React Query · Socket.IO  
> **Target:** Android (primary) · iOS  
> **Design Language:** Dark-first, green/red signal palette, smooth Reanimated 4 transitions

---

## 1. Product Overview

Slick AI is an AI-powered trading companion app. It connects to broker accounts (Deriv, MT5, Oanda), receives real-time trading signals generated by a deep-learning backend, and can execute trades automatically on the user's behalf. The app serves two kinds of users:

| Mode | What the app does |
|---|---|
| **Signal Delivery** | Receives AI signals; user decides when to trade manually |
| **Automated Trading** | AI executes trades autonomously; user monitors only |

### 2.2 Typography Scale

`xs=11` · `sm=13` · `md=15` · `lg=17` · `xl=20` · `2xl=24` · `3xl=28` · `4xl=34`  
Weights: `400 / 500 / 600 / 700 / 800`

### 2.3 Motion Principles

- **Entrance:** `withDelay(index * 80, withTiming(1, 400ms))` fade + spring slide-up per list card
- **Splash:** Logo scale `0.5 → 1` over 700 ms, text fade after 400 ms delay
- **Button press:** `withSpring(0.96)` scale down on press-in, spring back on release
- **Confidence bar:** Width animates from `0 → value%` over 600 ms with cubic easing

### 2.4 Navigation Structure

└── MainTabNavigator (Bottom Tabs)

## 3. Feature Specifications

### 3.1 Onboarding

- 3 swipeable slides with parallax opacity/translate animation via `scrollX` SharedValue
- Slides: "AI-Powered Trading" → "Connect Your Broker" → "Choose Your Mode"
- Skip button (hidden on last slide), Next/Get Started CTA
- Completion persisted in `SecureStore` key `slickai_onboarding_done`
- Never shown again after first completion

### 3.2 Authentication

**Login:**
- Email + password form with inline validation
- Input focus ring animation (border color + shadow)
- Biometric sign-in (FaceID / Fingerprint) via `expo-local-authentication`
- Failed-attempt counter displayed after first failure, lockout after 3 attempts (15 min)
- Lockout screen with countdown-style messaging
- JWT + refresh token stored in `SecureStore`

**Register:**
- Email + password + confirm password
- Password minimum 8 characters, match validation
- Same animated form pattern as Login

**Session Persistence:**
- `loadStoredAuth()` called on app boot reads token from `SecureStore`
- Token injected into all service `axios` clients on `isAuthenticated` change

### 3.3 Dashboard

**Header:**
- Time-based greeting ("Good morning / afternoon / evening, {firstName}")
- Live WebSocket connection indicator (green dot + "LIVE" pill)
- Animated entry (opacity + spring Y translate)

**Period Filter Tabs:**
- `1D | 7D | 30D | ALL` selector
- Active tab has primary background; inactive is card background
- Changing period re-fetches performance summary

**Summary Cards (2-column grid):**
- Large card: Total P&L with `AnimatedNumber` counter (color-coded green/red)
- Gradient overlay matches P&L direction (green tint / red tint)
- Small cards: Win Rate · Total Trades · Open Positions count

**Equity Curve:**
- `EquityChart` component using `react-native-svg`
- Shows timestamped equity data as a line chart
- Falls back gracefully when no data exists

**Open Positions List:**
- `TradeCard` per position with direction color stripe
- Shows: asset, direction badge, unrealized P&L (animated), entry/current price, size, duration, SL/TP
- "AI Managed" badge + lock icon on automated accounts
- Empty state with icon + contextual message

**Pull-to-Refresh:** Re-fetches open positions + performance summary simultaneously

**Skeleton loading:** 3 `SkeletonCard` placeholders while initial data loads

### 3.4 Signals

**Header:**
- Screen title + active signal count with live dot
- Total count label (right-aligned)

**Filter Chips (horizontal scroll):**
- `All | BUY | SELL | Active`
- Active chip: primary border + primary light background

**Signal Card (`SignalCard`):**
- Asset name · Direction badge (gradient buy/sell)
- Entry price · Stop Loss (red) · Take Profit (green)
- Animated confidence bar (0 → value% on mount)
- Confidence percentage label (color matches direction)
- Auto badge + "Executing automatically..." spinner for automated accounts
- EXPIRED badge + 45% opacity dimming for expired signals
- Signals expire 15 minutes after `generatedAt`

**Real-time updates:**
- New signals pushed via WebSocket `signal` event, prepended to list
- `setInterval(markExpiredSignals, 60s)` checks expiry
- Local push notification on new signal

**Empty state:** Radio icon + "Waiting for signals..." message

### 3.5 Trade History

**Stats Bar:**
- Total trades · Win Rate % · Net P&L
- Displayed above list when trades exist

**Filter Chips:** `All | BUY | SELL`

**Trade History Card:**
- Direction color left-stripe (4px)
- Asset · direction badge · P&L (color-coded)
- Entry → Exit price · lot size · hold duration
- Close reason badge (e.g. "TAKE PROFIT", "STOP LOSS")
- P&L percentage
- Exit timestamp

**Pull-to-Refresh**, skeleton loading, empty state

### 3.6 Accounts

**Account Card:**
- Gradient background (elevated → card)
- Status color left-stripe (active=green, error=red, circuit_breaker=orange, inactive=grey)
- Broker name (caps) + balance + currency
- Status badge with colored dot
- Subscription mode badge (chip: "Signal Delivery" blue / "Automated Trading" green)
- Disconnect button (destructive, confirmation alert)

**Connect Account Flow (bottom sheet modal):**

*Deriv (2-step):*
1. Step 1 — Paste PAT token → "Next →" calls `listDerivAccounts(pat)` API
2. Step indicator (two dots + line)
3. Step 2 — Account picker: shows each Deriv account with LIVE/DEMO badge, balance, currency
4. Auto-selects first active real account; user can override
5. "Connect" sends `{ broker, credentials: { login: pat, derivAccountId } }`

*MT5 / Oanda (1-step):*
- Login number · password · server fields
- "Connect" sends credentials directly

**Broker selector:** Horizontal scrollable chip selector (Deriv · MetaTrader 5 · Oanda)

**Error inline:** Red banner inside modal with icon

### 3.7 Settings

**Profile Card:**
- Gradient avatar circle with email initial
- Email + truncated user ID

**Preferences:**
- Push Notifications toggle (Switch)
- Haptic Feedback toggle (Switch)
- Currency display (value: USD, future: selectable)

**Subscription Mode per Account:**
- Card per connected account showing broker + balance + current mode badge
- Toggle switch: Signal Delivery ↔ Automated Trading
- Switching TO automated shows risk warning modal:
  - Warning icon + copy about capital risk
  - "Cancel" / "I Understand" buttons (orange CTA)
  - Only fires confirmation for automated; switching back is instant

**About Section:**
- Version · Privacy Policy · Terms of Service (links)

**Sign Out:**
- Destructive button → Alert confirmation → `logout()` clears SecureStore + resets store

## 4. State Management

### Stores (Zustand)

| Store | State | Key Actions |
|---|---|---|
| `authStore` | user, token, isAuthenticated, failedAttempts, lockedUntil, isLoading | login, logout, register, loadStoredAuth, incrementFailedAttempts, isLockedOut, getLockoutRemainingMs |
| `accountStore` | accounts[], isLoading, error | setAccounts, addAccount, removeAccount, setSubscriptionMode |
| `signalStore` | signals[], isLoading, error | setSignals, addSignal, updateSignal, markExpiredSignals |
| `tradeStore` | openPositions[], closedTrades[], performanceSummary, selectedPeriod, isLoading, error | setOpenPositions, addTrade, closeTrade, updatePosition, setPerformanceSummary, setSelectedPeriod |

### WebSocket Events

| Event | Handler |
|---|---|
| `signal` | `addSignal()` + local push notification |
| `trade_executed` | `addTrade()` + local push notification |
| `trade_closed` | `closeTrade(tradeId, exitPrice, pnl)` + notification |
| `position_update` | `updatePosition(tradeId, partialPosition)` |

## 5. Services

| Service | Responsibility |
|---|---|
| `authService` | POST /auth/login, /auth/register, /auth/biometric; biometric prompt via `expo-local-authentication` |
| `accountService` | GET /accounts, POST /accounts/connect, DELETE /accounts/:id, POST /accounts/deriv/list-accounts, POST /settings/subscription-mode |
| `signalService` | GET /signals |
| `tradeService` | GET /trades/open, GET /trades (closed), GET /trades/performance/:period |
| `websocketService` | Socket.IO client, reconnect logic, event emitter wrapper |
| `notificationService` | `expo-notifications` — request permissions, schedule local notifications |

All services inject `Authorization: Bearer {token}` via `setAuthToken(token)` called in `RootNavigator` on auth state change.
